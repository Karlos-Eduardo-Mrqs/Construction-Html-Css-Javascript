## Control Structures

Conditional structures are features offered by languages that allow you to check a condition and change the flow of algorithm execution. This allows you to define a specific action for different scenarios and obtain exactly the expected result when developing a website or application.

---

## Why is it necessary to use conditionals?

The use of conditional structures is practically indispensable in most projects, as they can perform different functions in a practical way. They allow you, for example, to control the content that will be displayed, create dynamic forms, develop interactive media, and make pages responsive.

---

## Conditional Structure If, Else If, and Else

- **If:**
You can use `if` in JavaScript to specify code that should be executed when the condition is true.

![image](https://github.com/user-attachments/assets/68c08bad-4035-4c0c-af43-5ef28cc9beba)

- **If / Else:**
Specifies a block of code to execute if the condition is true and another block if it is false.

![image](https://github.com/user-attachments/assets/33a2bc66-b5a3-417d-b754-43a0e41f1e58)

- **If / Else If / Else:**
Allows you to test multiple sequential conditions. If the first condition is false, the next condition is tested, and so on.

![image](https://github.com/user-attachments/assets/3ae37d6b-e366-454b-8d50-189d61c5c876)
