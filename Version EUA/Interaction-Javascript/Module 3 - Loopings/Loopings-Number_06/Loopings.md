## What are loops?

Looping is a term used in programming to describe the repetition of a set of instructions or actions. It is a fundamental structure in many programming languages and is widely used to automate tasks and control the flow of a program.

## Types of Loops

In total, we have three types of loops, each with its own characteristics and purposes:

---

## 1. Repetition with Test at the Beginning

### For Loop

This is a repetition structure that allows you to execute a block of code a specified number of times. It is especially useful when you know exactly how many times the code needs to be repeated.

The for loop is composed of three main parts:

- Initialization (initial repetition counter);
- Continuation condition (how many times this repetition will occur);
- Update (increment `++` or decrement `--`).

### Foreach Loop

The `foreach` loop is used to iterate through a collection of elements, such as an array or list, and execute a block of code for each element. It is especially useful when you want to perform an action for each item in a collection.

## 2. Loop with Test at the End

### Do-While Loop

The do-while loop is similar to the for loop `while`, but the condition is checked **after** each iteration of the loop. This means the code block will be executed at least once, even if the condition is false from the start.

## 3. Repetition with a Control Variable

### While Loop

This is a repetition structure that executes a block of code as long as a certain condition is true. It's useful when you don't know exactly how many times the code needs to be repeated, but rather until a condition is met.

The condition is checked **before** each iteration of the loop.
