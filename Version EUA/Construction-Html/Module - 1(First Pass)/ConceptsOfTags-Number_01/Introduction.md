# WHAT IS HTML? 🤔

**Hypertext Markup Language (HTML)** is not a programming language per se, but rather a markup language, as its name suggests.

Its main goal is to structure the content of a web page through markup elements known as **tags**, which inform the browser how each part of the content should be displayed or interpreted.

Unlike programming languages that perform actions and calculations, like JavaScript or Python, HTML serves as the **structural foundation** of any web document. It defines elements such as headings, paragraphs, lists, images, links, tables, forms, and much more—allowing browsers to properly interpret and present the content to users in an organized way.

**HTML tags** are written between angle brackets (`< >`) and generally appear in pairs — an opening tag and a closing tag. For example: `<p>` opens a paragraph and `</p>` closes it. Some tags are self-closing, like `<img />`, used to insert images.

## HTML Versions 🧰

The HTML language has gone through several revisions and improvements over time. Currently, the **most recent and recommended version is HTML5**, which is fully supported by modern browsers. While older versions may still work, they are not recommended for new projects due to limited features.

Below are the most important versions in HTML’s evolution:

### HTML 4.01

Finalized in 1999, this version was widely adopted for over a decade. It marked an important milestone in the standardization of web development and introduced features like style sheets (CSS) and a better separation of content and presentation. Although still found in legacy systems, it is now considered outdated.

### XHTML 1.0 / 1.1

Starting in the 2000s, XHTML—a combination of HTML and XML (Extensible Markup Language)—became popular. This version aimed to enforce stricter coding rules and improve standardization. Though widely used at the time, XHTML lost popularity with the rise of HTML5. Its usage today is rare and typically limited to very specific contexts. It can still be used with HTML5, but this practice is uncommon and will not be covered in this course.

### HTML5

HTML5 was officially released in 2014 and represented a major leap in the language. It introduced several native features that previously required scripts or external plugins (like Flash). Key innovations include:

- **New semantic tags**, such as `<section>`, `<article>`, `<nav>`, and `<footer>`, making content more organized and understandable for both humans and machines.
- **Native audio and video support**, using `<audio>` and `<video>` tags.
- **Improved form support**, with new `<input>` types and built-in validation.
- **Integration with modern APIs**, like geolocation, local storage (localStorage), graphics (Canvas and SVG), and more.

Importantly, since HTML5, the language is now considered a **“living standard.”** This means it will no longer receive numbered versions and will instead evolve continuously to meet the needs of the modern web, maintained by organizations like the W3C and the WHATWG.

## Historical Summary of HTML 📕

HTML was created by **Tim Berners-Lee**, a physicist at CERN (European Organization for Nuclear Research) in Switzerland, in 1991. At the time, he sought a way to efficiently share scientific documents among researchers through the newly created internet.

His core idea was to create a **hypertext system**—text that could contain links to other documents, allowing interlinked navigation between different pieces of content. The first version of HTML contained only **18 tags**, but it was enough to build simple pages with titles, lists, links, and paragraphs.

With the rapid growth of the web, HTML became the **foundation of the modern internet**. The language evolved quickly, gaining new features and adapting to emerging devices and technologies. Today, it is considered the **universal standard** for building web pages, essential for developing websites, blogs, social networks, and online applications.

The biggest leap in HTML’s evolution occurred with the **release of HTML5 in 2014**, which brought more dynamic and flexible tools, consolidating HTML as the foundation of front-end development.
