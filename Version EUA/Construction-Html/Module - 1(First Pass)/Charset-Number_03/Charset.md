## Charset

A **charset** is known as a character set — essentially, a collection of symbols. For example, the alphabet is a set of letters from A to Z. Around the world, different regions use different scripts and characters, such as the **Brazilian**, **Chinese**, **Arabic**, and **Hebrew** alphabets.

## ASCII Table

In the field of technology, the concept is similar. There’s even a dedicated table — the **ASCII Table**, or the **American Standard Code for Information Interchange**.

ASCII is based on the Roman alphabet and is used to standardize the way computers represent letters, numbers, symbols, and control characters.

![4e6047eeebc1470cd6c8c5ae082975e3](https://github.com/Karlos-Eduardo-Mrqs/Trabalhos_Operacionais/assets/172524894/6cd28b1c-4567-4ba0-ad52-db2419d2ed29)

## Meta Tag

Knowing this, we can use the **`<meta>`** tag to define the character set used by the HTML document. This tag is typically placed inside the `<head>` of the page.

The most common options are:

- **UTF-8**: Supports virtually all written languages and special characters.
- **ASCII**: Limited to the characters of the ASCII table.

Example of usage:

```html
<meta charset="UTF-8" />
```

This tag is **self-closing**, so it doesn’t need a closing `</meta>` tag.
