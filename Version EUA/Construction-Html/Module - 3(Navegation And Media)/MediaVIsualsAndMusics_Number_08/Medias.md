## Musical and Visual Media 🎛️

In this module, we'll learn how to manipulate images, audio, and videos in our HTML pages. Let's go!

## Image 📠

We use the ``<img />`` tag with the following attributes:

- **src:** Defines the name of the file/image to be used.
- **width:** The width in pixels of the image, i.e., its thickness.
- **height:** The height in pixels of the image, i.e., its height.
- **title:** These display explanatory text, explaining what should be displayed.

```html
<img src="alanzoka.jpg" width="350" height="200" title="Image of Alanzoka" />
```

![ExampleImg](https://github.com/Karlos-Eduardo-Mrqs/Construcao-Html-Css-Javascript/assets/172524894/eb3d3b19-4512-4c87-a3d5-665444783f9c)

### Image Types

- **JPEG – Joint Photographic Experts Group**

> Lossy compression format, ideal for photos with lots of detail and color.

- **JPG – Joint Photographic Experts Group**

> Same as JPEG, just a variation of the extension (limited to 3 letters on older systems, like MS-DOS).

- **SVG – Scalable Vector Graphics**

> Scalable XML-based vector image, excellent for icons, logos, and illustrations that need to maintain quality at any size.

- **PNG – Portable Network Graphics**

> Lossless format, great for images with transparent backgrounds and graphics with few details (such as buttons or icons).

- **BMP – Bitmap**

> Uncompressed image format, generated by Windows. Takes up a lot of space and is rarely used on the web.

## Anchor and images 🖇️

You can use images inside an anchor (``<a>``):

```html
<a href="https://www.youtube.com/@alanzoka/videos" title="Alanzoka's Channel" target="_blank">
<img src="im.jpg" width="350" alt="Alanzoka's Image" />
</a>
```

## Music 🎼

To play audio, we use the ``<audio></audio>`` tag with the following attributes:

- **controls:** Defines the play, pause, and download controls. In other words, interaction controls. - **src:** Same function for images, except that the difference is that it defines the audio that will be used.
- **type:** The file type. Example: "audio/mp3".

```html
<audio controls src="musica.mp3" type="audio/mp3"></audio>
```

## Audio File Types 🖇️

The best-known is undoubtedly the **MP3**. [However, other file types are available at the pinned link here](https://frahm.com.br/formatos-de-audio/).

## Videos 📷

The ``<video> </video>`` tag allows you to insert videos with the following attributes:

- **controls:** Defines the controls for start, pause, download, etc. In other words, interaction controls.
- **src:** Same function for audio, with the difference that it defines the video that will be used.
- **type:** The file type/file type. Example: "video/mp4".
- **width:** The width in pixels that the video will have, that is, its Thickness.
- **height:** The pixel height of the video, i.e., its height.

```html
<video controls src="ApertouOPlay.mp4" type="video/mp4" width="1024" height="768"></video>

```

### Video File Types ⚓

The best known is undoubtedly **MP4**. [However, other file types are available at the link provided here](https://mailchimp.com/pt-br/resources/video-formats/)

## Other Related Tags

There is another way to use videos within HTML. Using the ``<iframe> </iframe> AND <embed> </embed>`` tags.

### ▶️ Difference between ``<iframe>`` and ``<embed>``

#### ``<embed>`` Tag

![ExampleVideoEmbled](https://github.com/Karlos-Eduardo-Mrqs/Construcao-Html-Css-Javascript/assets/172524894/4d08bf9b-0d9a-4f04-8d6d-e857d85fbbc8)

The ``<embed>`` tag allows you to embed media, such as videos and PDF files, directly into the page.

*⚠️ Disadvantages:*

- Displays a dark frame around the video;
- Does not allow opening in full screen;
- Control buttons are small;
- Interface considered less user-friendly.

**Therefore, it is less commonly used for videos today.**

#### ``<iframe>`` Tag

![ExampleIframe](https://github.com/Karlos-Eduardo-Mrqs/Construcao-Html-Css-Javascript/assets/172524894/91d691cc-bc65-42ad-bfe9-8a806ff229f9)

The ``<iframe>`` tag is the most recommended when we want to embed videos from external platforms, such as YouTube.

**💡 How to embed YouTube videos with ``<iframe>``**

- Access the desired video on YouTube;
- Click Share;
- Then click Embed;
- Copy the ``<iframe>`` code that appears;
- Paste it into your HTML (e.g., in Visual Studio Code).

```html
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" title="YouTube video player" frameborder="0" allowfullscreen></iframe>
```

✅ Use ``<iframe>`` to embed videos professionally and with a better user experience.

> 💡 Extra Tip: On YouTube, choose a video and then go to **Share → Embed** and copy the `<iframe>` code to easily insert a video into your HTML page.
