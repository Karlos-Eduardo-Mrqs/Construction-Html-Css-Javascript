# 🌐 Construction HTML

Welcome to **Construction HTML**, a practical and comprehensive guide for anyone wanting to learn HTML from basic to advanced — divided into 6 progressive modules !

This repository is perfect for those starting to build web pages and who want to understand how the main elements that compose a page work.

---

## 🗂️ Modules

### 1. [First Steps](../Construction-Html/Module%20-%201(First%20Pass)/) 💓  

Learn the basic structure of an HTML document, including essential tags like `<html>`, `<head>`, `<body>`, initial formatting, and best practices for starting HTML coding.  

![Module 1](https://github.com/user-attachments/assets/4e2105ab-5cdb-4b43-ad91-7316b9d5eb58)

### 2. [Manipulation With Texts](../Construction-Html/Module%20-%202(Manipulation%20With%20Texts)/) 📖  

Explore how to work with textual content on the web: headings (`<h1> - <h6>`), paragraphs (`<p>`), lists (`<ul>`, `<ol>`), and formatting tags like `<strong>`, `<em>`, and `<address>`.  

![Module 2](https://github.com/user-attachments/assets/903a94f6-0cdb-4975-b34f-8ebd80b2315c)

### 3. [Navigation and Media](../Construction-Html/Module%20-%203(Navegation%20And%20Media)/) ⏯️  

Learn how to create navigation with `<a>`, and insert/manipulate images and videos using `<img>` and `<video>`. Understand attributes to control media display.  

![Module 3](https://github.com/user-attachments/assets/ce802317-77b2-42e3-a946-d2a85e92922e)

### 4. [Tables](../Construction-Html/Module%20-%204(Tables)/) 📑  

Understand how to build and format tables with `<table>`, `<tr>`, `<td>`, making your data clear and well organized.  

![Module 4](https://github.com/user-attachments/assets/f4518924-2b32-4d5e-b783-547adc543463)

### 5. [Forms](../Construction-Html/Module%20-%205(Forms)/) 📝  

Learn to collect user data through forms using `<form>`, `<input>`, `<select>`, `<textarea>`, and how to send data to a server.  

![Module 5](https://github.com/user-attachments/assets/e708296d-e6c8-4cbd-bfdf-25977e4a8b2d)

### 6. [Web Development Overview](../Construction-Html/Module%20-%206(Developing%20In%20Web)/) 📔  

Get an overview of HTML structures on large websites like Globo.com and Globoplay. Learn about important tags like `<nav>`, `<div>`, `<section>`, and more.  

![Module 6](https://github.com/user-attachments/assets/6a70e47a-e148-4461-a47e-58f67a1e86a2)
