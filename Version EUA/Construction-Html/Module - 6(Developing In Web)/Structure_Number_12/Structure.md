## 🧠 Understanding the Organization

By analyzing these images, you'll see that each section of the page is an independent block — and within each, we have elements such as:

- Headings
- Paragraphs
- Images
- Links
- Search fields
- Navigation menus

This block separation makes the page more organized, and each block can be manipulated individually with HTML and CSS.

## 🧱 But why divide it into blocks?

1. ✅ Content organization
2. ✅ User reading and navigation
3. ✅ Applying styles with CSS
4. ✅ Reusing sections on the site
5. ✅ Code maintenance and clarity

> 💡 Each block can be created with structural tags such as ``<header>``, ``<section>``, ``<article>``, ``<aside>``, and ``<footer>``. Let's learn more about them below.
