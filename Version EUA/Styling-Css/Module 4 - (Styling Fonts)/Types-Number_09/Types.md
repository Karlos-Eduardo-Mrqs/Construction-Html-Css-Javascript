## 🔤 `font-family`

![image](https://github.com/user-attachments/assets/f3e121ae-5a5f-40ae-bae2-e3b423d839dd)

By default, if no font style is specified, the browser uses **Times New Roman**:

![0\_QBGG7EdJWTMq6goC](https://github.com/user-attachments/assets/0181afd3-a366-475e-8f60-40ad967cdfb3)

### 🧬 Difference between `serif` and `sans-serif`

* `serif`: fonts with **decorative tips** (e.g., Times New Roman)
* `sans-serif`: fonts **without these tips** (e.g., Arial, Verdana)

![BP-Serif-SansSerif-Graphic1-862x518](https://github.com/user-attachments/assets/725a3018-c9e3-444c-82f9-079a9e05476c)

### 📦 Example Practical

To apply the **Verdana** font to the beige box:

```css
font-family: Verdana, Geneva, Tahoma, sans-serif;
```

Or, in Visual Studio Code:

> CTRL + Space + Name of the desired font

![image](https://github.com/user-attachments/assets/500c317c-eb99-4491-a90c-4acc406d924f)

## 🌐 Importing Custom Fonts

You can use external fonts with [Google Fonts](https://fonts.google.com/):

### 1️⃣ Via `<link>`

* Copy the generated `link` code and paste it **above your CSS `<link>` tag** in the HTML.

### 2️⃣ Via `@import`

* Copy the `@import` code and paste it **at the beginning of your CSS**.

## ✨ `font-style`

Sets the **style** of the text:

| Value | Effect |
| --------- | ---------------------------------------- |
| `normal` | Keeps the default text |
| `italic` | Tilts text to the right (italics) |
| `oblique` | Similar to `italic` (less commonly used) |
