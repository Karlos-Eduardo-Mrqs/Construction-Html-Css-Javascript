## 🎨 Decoration

Let's decorate the texts with **color**, **alignment**, **spacing**, **line height**, and **text transformations**.

### 🖍️ Text Color – `color`

To change the font color, use:

```css
color: red;
```

You can also use `currentColor` and `inherit`.

## 📐 Alignment – `text-align`

Controls text alignment:

```css
text-align: center;
```

| Value | Effect |
| --------- | ------------------ |
| `left` | Aligns left |
| `right` | Aligns right |
| `center` | Centers text |
| `justify` | Justifies text |

## 🔠 Text Transformation – `text-transform`

Changes the font format:

```css
text-transform: uppercase;
```

| Value | Effect |
| ------------ | -------------------------------------------- |
| `capitalize` | Capitalize the first letter of each word |
| `uppercase` | All letters in uppercase |
| `lowercase` | All letters in lowercase |
| `none` | No transformation (default) |
