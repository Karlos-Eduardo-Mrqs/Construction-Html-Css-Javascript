## CSS Standardization (Reset CSS)

Reset CSS is a technique (or set of CSS styles) designed to standardize the default styling of HTML elements across all browsers.

The goal is to create a consistent and predictable foundation for web development by eliminating the default styling variations that each browser applies individually.

---

## How do browsers interpret this?

Each browser has its own default presentation for HTML elements, which can lead to layout conflicts in web projects.

This individualized behavior was (and still is) a frequent challenge for front-end developers, as each browser applies different default styles.

Although it's a simple technique, reaching a consensus on how to "force" all browsers to behave the same way wasn't easy.

---

## How to use Reset CSS?

We know that Reset CSS is a style sheet like any other, and can be used:

- Directly within the HTML file;
- Or imported from an external file (recommended for reuse in multiple files).

The most common approach is to add Reset CSS before starting to style the project to remove the browser's default formatting.

Inserting it mid-project can cause problems, as the layout may have been created with the browser's default styles in mind—not the standardized base after the reset.
