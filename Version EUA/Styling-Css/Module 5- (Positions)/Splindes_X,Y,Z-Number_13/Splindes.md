## 📦 View Position

### Cartesian Plane

In the Cartesian plane, we have two axes: X (width) and Y (height).
In CSS, there is also the Z axis, which represents depth and controls the overlap of elements.

![image](https://github.com/user-attachments/assets/83e7933c-fe6a-4d63-8f19-b2a481d992be)

### Z-Index

The z-index controls the hierarchy of element overlap: the higher the value, the more "front" it is on the screen.

![image](https://github.com/user-attachments/assets/d09cd865-4941-4df2-9a02-fc3ed7bf7a91)

In the example, Box3 overlaps the others, but Box2 is further ahead because it has a higher z-index.

![image](https://github.com/user-attachments/assets/5d969c5f-d953-4fdb-b28f-a111a20c42fd)

Changing the values:

- Box1 with z-index: 3
- Box3 with z-index: 4

Box3 is highlighted in front of the others.

![image](https://github.com/user-attachments/assets/b399590f-8579-48da-8508-dce9932b3a33)

If all elements have the same z-index, the display order follows the order of creation (top-down).
