# 🌐 Construction HTML

Bem-vindo ao **Construction HTML**, um guia prático e completo para quem deseja aprender HTML do básico ao avançado, dividido em 6 módulos progressivos!  

Este módulo é ideal para quem está começando a construir páginas web e quer entender como funcionam os principais elementos que compõem uma página.

---

## 🗂️ Módulos

### 1. [Primeiros Passos](./Módulo%20-%201(Primeiros%20Passos)/) 💓  

Neste módulo, você aprenderá sobre a estrutura básica de um documento HTML, incluindo o uso das tags essenciais (`<html>`, `<head>`, `<body>`), formatação inicial e boas práticas para começar a trabalhar com HTML.  

![Módulo 1](https://github.com/user-attachments/assets/4e2105ab-5cdb-4b43-ad91-7316b9d5eb58)

### 2. [Manipulação com Textos](./Módulo%20-%202(Manipulação%20De%20Textos)/) 📖  

Aqui, você aprenderá a trabalhar com conteúdo textual na web: utilização correta de títulos (`<h1>` a `<h6>`), parágrafos (`<p>`), listas (`<ul>`, `<ol>`) e elementos de formatação como `<strong>`, `<em>`, além de citações com `<address>`.  

![Módulo 2](https://github.com/user-attachments/assets/903a94f6-0cdb-4975-b34f-8ebd80b2315c)

### 3. [Navegação e Mídia](./Módulo%20-%203(Navegação%20e%20Mídia)/) ⏯️  

Aprenda a adicionar links de navegação com `<a>`, inserir e manipular imagens e vídeos usando `<img>` e `<video>`. Entenda como utilizar atributos para ajustar a apresentação dos elementos multimídia.  

![Módulo 3](https://github.com/user-attachments/assets/ce802317-77b2-42e3-a946-d2a85e92922e)

### 4. [Tabelas](./Módulo%20-%204(Tabelas)/) 📑  

Este módulo aborda a criação de tabelas com as tags `<table>`, `<tr>`, `<td>`, além de técnicas para formatar tabelas e apresentar informações de maneira clara e organizada.  

![Módulo 4](https://github.com/user-attachments/assets/f4518924-2b32-4d5e-b783-547adc543463)

### 5. [Formulários](./Módulo%20-%205(Formulários)/) 📝  

Entenda como coletar dados do usuário utilizando formulários HTML. Você verá as tags `<form>`, `<input>`, `<select>`, `<textarea>` e aprenderá como enviar esses dados para um servidor.  

![Módulo 5](https://github.com/user-attachments/assets/e708296d-e6c8-4cbd-bfdf-25977e4a8b2d)

### 6. [Desenvolvimento Web](./Módulo%20-%206(Modelando%20na%20Web)/) 📔  

Aqui, você terá uma visão geral de como a estrutura HTML funciona em grandes sites, como Globo e Globoplay. Também aprenderá sobre as principais tags como `<nav>`, `<div>`, `<section>` e outras.  

![Módulo 6](https://github.com/user-attachments/assets/6a70e47a-e148-4461-a47e-58f67a1e86a2)

## 💻 Para quem é este guia?

- 🔰 Iniciantes que querem aprender HTML do zero.  

- 👨‍🎓 Desenvolvedores que desejam reforçar suas habilidades em HTML.  

- 🙆 Qualquer pessoa interessada em construir uma estrutura sólida para páginas web.

## ⚙️ Tecnologias utilizadas

- **HTML 🏬** — Linguagem de marcação para construção de páginas.  

- **CSS 🖌️** — Utilizado nos exemplos para estilização básica das páginas.

## 👓 Observação

Para aproveitar melhor o conteúdo, **siga os módulos em ordem**. Dentro de cada módulo, leia os arquivos começando pelo `Número_1` (exemplo: `ConceptyTags-Número_01`, `HtmlStructure-Número_02`), para não se perder, pois os conteúdos estão interconectados.
