## Citações No Html

No HTML, podemos “referenciar” um texto já criado em nosso site utilizando a tag ``<blockquote> </blockquote>``. A estrutura básica é:

```html
  <blockquote cite="https://g1.globo.com/economia/noticia/2024/06/20/dolar-ibovespa.ghtml">
        No dia anterior, a moeda norte-americana avançou 0,15%, cotada a R$5,4417, renovando o maior patamar desde janeiro de 2023. Já o principal índice acionário da bolsa de valores brasileira fechou com alta de 0,53%, aos 120.261 pontos.
  </blockquote>
```

## Tag Address

Também, podemos citar endereços com a tag ``<address> </address>`` sendo sua estrutura assim:

```html
  <address>
        Rua São Agostinho Número 67, Centro <br>
        São Paulo/SP <br>
        CEP: 010100-00
    </address>
```

## Conceito de Atributo

Você deve ter notado que a tag ``<blockquote>`` possui um termo chamado cite, que indica a fonte do texto citado. Esse termo é chamado de atributo, e serve para adicionar funcionalidades ou características extras a uma tag.

Por exemplo, na imagem abaixo, os atributos são usados para modificar a cor de um parágrafo para azul:

![ExemplosDeAtributo](https://github.com/Karlos-Eduardo-Mrqs/Trabalhos_Operacionais/assets/172524894/e7296dd7-996c-49fa-9103-8ae7e76a262e)

Através dos atributos, podemos controlar o comportamento das tags e personalizar seu funcionamento conforme a necessidade.
