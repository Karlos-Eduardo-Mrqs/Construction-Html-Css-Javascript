## Propriedade `resize`

O CSS possui o atributo `resize` que controla como a área de texto pode ser redimensionada.  

Podemos permitir o redimensionamento:

- Para ambos os lados (`both`) — padrão;
- Apenas horizontalmente (`horizontal`);
- Apenas verticalmente (`vertical`);
- Ou bloquear completamente (`none`).
