## 🎨 Decoração

Vamos decorar os textos com **cor**, **alinhamento**, **espaçamento**, **altura** de linha e **transformações de texto**.

### 🖍️ Cor do Texto – `color`

Para mudar a cor da fonte usamos:

```css
color: red;
```

Também é possível usar `currentColor` e `inherit`.

## 📐 Alinhamento – `text-align`

Controla o alinhamento do texto:

```css
text-align: center;
```

| Valor     | Efeito             |
| --------- | ------------------ |
| `left`    | Alinha à esquerda  |
| `right`   | Alinha à direita   |
| `center`  | Centraliza o texto |
| `justify` | Justifica o texto  |

## 🔠 Transformação do Texto – `text-transform`

Modifica o formato das letras:

```css
text-transform: uppercase;
```

| Valor        | Efeito                                      |
| ------------ | ------------------------------------------- |
| `capitalize` | Primeira letra de cada palavra em maiúscula |
| `uppercase`  | Todas as letras em maiúsculas               |
| `lowercase`  | Todas as letras em minúsculas               |
| `none`       | Sem transformação (padrão)                  |
