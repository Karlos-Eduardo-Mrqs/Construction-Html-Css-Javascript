# 🎨 Styling CSS

Bem-vindo ao **Styling CSS**, um guia completo para aprender a estilizar páginas da web com CSS!  

Este módulo está dividido em 6 módulos que cobrem desde conceitos básicos até técnicas avançadas de design para criar interfaces modernas e interessantes.

---

## 🗂️ Módulos

### 1. [Primeiros Passos](./Módulo%201%20-%20(Primeiros%20Passos)/) 🧑‍🎓  

Descubra os fundamentos do CSS: como ele interage com o HTML, como adicionar estilos a um documento, usar seletores básicos e a sintaxe correta para aplicar regras de estilo.  

![Módulo 1](https://github.com/user-attachments/assets/d15f9d5a-a848-4846-bfe0-2f8b3949ca54)

### 2. [Aparência](./Módulo%202%20-%20(Aparência)/) 🎨  

Neste módulo, você aprenderá a controlar a aparência visual dos elementos, desde fundo, bordas, até sombras. Veja como estilizar os detalhes que fazem seus componentes se destacarem, usando propriedades como background, border, box-shadow e mais.  

![Módulo 2](https://github.com/user-attachments/assets/dcabee82-7e1b-49ce-b3c7-acbc139039e7)

### 3. [Espaçamento](./Módulo%203%20-%20(Espaçamento)/) 🔲  

Aprenda a controlar o espaçamento dos seus elementos com margin, padding e box-sizing. Entenda como garantir um layout adequado e espaçamento consistente, essencial para uma página organizada e responsiva.  

![Módulo 3](https://github.com/user-attachments/assets/b0766086-f7bb-4d3b-891b-f39202ca3491)

### 4. [Estilizando Fontes](./Módulo%204%20-%20(Estilos%20De%20Fontes)/) ✍️  

Estilizar fontes é uma das principais maneiras de melhorar a legibilidade e a estética de uma página. Aqui você verá como modificar famílias de fontes, tamanhos, line-height, espaçamento entre letras e outras propriedades relacionadas ao texto.  

![Módulo 4](https://github.com/user-attachments/assets/533a4091-e2e3-408b-a862-966b4da188bd)

### 5. [Posicionamento](./Módulo%205%20-%20(Posições)/) 🧑‍🎨  

Este módulo foca em técnicas de layout. Aprenda a posicionar elementos usando propriedades como position, float, z-index e entenda como display e flexbox funcionam para criar layouts flexíveis e responsivos.  

![Módulo 5](https://github.com/user-attachments/assets/6d28f47c-8f43-4105-a5a6-9f66db58ad77)

### 6. [Componentes HTML](./Módulo%206%20-%20(Componentes%20Html)/) 💻  

Neste módulo, você verá como estilizar elementos HTML comuns, como botões, formulários e navegações. Vamos cobrir a criação de componentes reutilizáveis e estilizados de forma eficiente para criar uma interface amigável ao usuário.  

![Módulo 6](https://github.com/user-attachments/assets/965f8c38-44cc-4b7b-a1df-49de13cf35fc)
