## Operadores

Os operadores são elementos essenciais na linguagem de programação JavaScript. Eles permitem realizar diversas operações, desde cálculos matemáticos simples até manipulações complexas de dados.  
Neste artigo, vamos explorar os operadores em JavaScript e descobrir como eles podem potencializar seu código.

---

## Tipos de Operadores

Nas linguagens de programação, possuímos três tipos principais de operadores: **Aritméticos**, **Lógicos** e de **Comparação**.

---

### Operadores Aritméticos

Os operadores aritméticos são usados para realizar operações matemáticas básicas.

![image](https://github.com/user-attachments/assets/18c720c3-6746-440d-9cb4-ecc7fb049a40)

#### Representação Matemática

1. Soma: `10 + 5`  
2. Subtração: `10 - 5`  
3. Multiplicação: `10 * 5`  
4. Divisão: `10 / 5`  
5. Exponenciação: `10 ** 5` (ou `10 * 10 * 10 * 10 * 10`)  
6. Resto da Divisão (Módulo): `10 % 5` (exemplo: divisão `10 / 5 = 2` com resto `0`)  
7. Incremento: `10 + 1`  
8. Decremento: `5 - 1`  

---

### Operadores de Atribuição

Os operadores de atribuição são usados para atribuir valores a variáveis. O operador principal é o símbolo `=`.  
Além disso, é possível combinar operadores aritméticos com atribuição para operações simplificadas.

![image](https://github.com/user-attachments/assets/dd59cf84-e467-4485-a386-802b214f44e5)

#### Exemplos Matemáticos

1. Soma: `x += 5` equivale a `x = x + 5`  
2. Subtração: `x -= 5` equivale a `x = x - 5`  
3. Multiplicação: `x *= 5` equivale a `x = x * 5`  
4. Divisão: `x /= 5` equivale a `x = x / 5`  
5. Resto da Divisão: `x %= 5` equivale a `x = x % 5`

---

## Atenção

O operador de subtração `-` pode resultar em valores negativos. Por exemplo, `8 - 16 = -8`.

O operador módulo (resto da divisão) `%` retorna o resto da divisão entre dois números. Veja a imagem abaixo para entender:

![divisão e módulo](https://github.com/user-attachments/assets/bf6dcdec-19c0-4564-b7c5-ffdb87a07fad)

**Explicação:**  
O quociente é o resultado da divisão inteira, enquanto o resto é o que sobra.  
Por exemplo, `10 / 5 = 2` e o resto é `0`.
