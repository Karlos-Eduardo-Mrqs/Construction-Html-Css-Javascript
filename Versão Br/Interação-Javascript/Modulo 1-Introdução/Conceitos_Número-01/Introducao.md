# O que é JavaScript?

JavaScript é uma linguagem de programação leve usada por desenvolvedores para criar interações dinâmicas em páginas da web, aplicativos, servidores, jogos e muito mais. Ela adiciona elementos que melhoram a experiência do usuário, como menus suspensos, gráficos animados e cores de fundo dinâmicas. Diferentemente do CSS, que apenas estiliza, o JavaScript permite interatividade e manipulação da página em tempo real.

---

## Características

JavaScript é uma linguagem de **scripting**, ou seja, permite controlar uma ou mais aplicações através de scripts inseridos em páginas HTML. Geralmente, linguagens de scripting são **interpretadas**, o que significa que não precisam ser compiladas para rodar — o código é executado diretamente pelo navegador.

No caso do JavaScript, ele permite controlar o comportamento dos navegadores e a interação do usuário por meio de trechos de código embarcados nas páginas.

---

### Resumo Histórico

Com o crescimento da internet para o público geral, houve a necessidade de aumentar a interação dos usuários com as páginas web. A Netscape, criadora do navegador que dominou o início dos anos 90, lançou o **LiveScript**, uma linguagem simples para executar scripts diretamente no navegador.

![Microsoft Visual Studio Services Icons](https://github.com/user-attachments/assets/5bf6105d-5275-4fa9-9a51-0e944feb4639)

Aproveitando o sucesso do Java, a Netscape rebatizou o LiveScript como **JavaScript** após um acordo com a Sun Microsystems para aproveitar a popularidade do Java e impulsionar ambas as tecnologias.  

A Microsoft, então vice-líder no mercado de navegadores, adicionou suporte a scripts em **VBScript** no Internet Explorer e criou sua própria versão do JavaScript, chamada **JScript**.

## Java x JavaScript

Apesar dos nomes semelhantes, Java e JavaScript são tecnologias distintas com diferenças fundamentais:

1. **Modelo de linguagem:**  
   Java é uma linguagem de programação orientada a objetos (OOP), enquanto JavaScript é uma linguagem de scripts que também suporta OOP, mas com um modelo diferente.

2. **Compilação:**  
   Java precisa ser compilado antes de ser executado, enquanto JavaScript é interpretado diretamente pelo navegador, sendo inserido como texto no HTML.

3. **Ambiente de execução:**  
   JavaScript é tradicionalmente executado em navegadores web, enquanto Java pode rodar em múltiplas plataformas através da Máquina Virtual Java (JVM).

4. **Características da linguagem:**  
   Java foi projetado como uma linguagem puramente orientada a objetos, enquanto JavaScript usa um modelo baseado em protótipos, sem classes tradicionais (embora classes tenham sido introduzidas nas versões mais recentes).

5. **Simplicidade:**  
   JavaScript é geralmente considerado mais simples e fácil de aprender, especialmente para manipulação de páginas HTML, enquanto Java exige um entendimento mais profundo de conceitos como classes e objetos.

Em resumo, Java e JavaScript têm propósitos e características diferentes, apesar da similaridade nominal que pode gerar confusão.
